Pipes 5.0 brings artwork-led discovery, a floating circular player, gesture queue controls, and a refined Oxocarbon design with Libron typography.

- Libron regular and bold throughout the app, bundled locally with the font license and copyright notices.
- Recognizable navigation icons; decorative dot-and-dash strips removed.

### Upgrade from 4.x

Download `app-release.apk` from this page and install it over your existing official Pipes app to keep your library and settings. The 4.x updater does not recognize 5.x tags, so this first upgrade requires a direct download. Pipes 5.0 supports subsequent 5.x updates in the app.

Android 8.0 or newer is required. This release is built, tested, linted, and signed by GitHub Actions. Visual and touch verification on a running device remains pending.
